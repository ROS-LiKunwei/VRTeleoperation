# FA C++ 重构测试与推荐配置

## 结论及适用范围

推荐 `precision_200hz` 配置：200 Hz 控制、1000 Hz 轨迹采样、20 ms 期望轨迹时长、IK 位置/姿态接受门限 0.2 mm / 0.002 rad。

在下述简化运动学模型和低速可达轨迹条件下，最终构建的左右臂最大位置误差分别为 **0.2883 mm / 0.3350 mm**，最大姿态误差分别为 **0.000766 rad / 0.000814 rad**，满足模型内 1 mm / 0.01 rad 门限。

10 分钟实时基准的全部截止时间判定：**通过**。没有进行物理机器人、外部 TCP 测量、PICO 新传感器帧率或 Android APK 的验证。这里的“推荐”指已测试候选中满足模型内精度条件且最大位置误差最小的配置，不代表所有工作空间、速度和负载下的全局最优。

## 单因素配置比较

固定 IK 门限、迭代预算、速度/加速度约束和模型，仅调整轨迹期望时长；每组运行 4000 步，覆盖 20 s 模拟时间。

| 轨迹时长 ms | 左臂最大位置 mm | 右臂最大位置 mm | 最大姿态 rad | 计算 P99 ms | 失败步数 |
|---|---|---|---|---|---|
| 20 | 0.2840 | 0.3350 | 0.000814 | 0.4158 | 0 |
| 40 | 0.4344 | 0.4833 | 0.001175 | 0.3030 | 0 |
| 60 | 0.6118 | 0.6824 | 0.001669 | 0.2998 | 0 |
| 80 | 0.7899 | 0.8825 | 0.002165 | 0.2984 | 0 |

四组都满足该轨迹下的模型内精度门限；20 ms 的同时刻位置误差最低，因此作为推荐配置。不同实验运行时桌面负载不同，微小耗时差异不作为算法优劣结论。

| 输出参考峰值关节加速度 | 1.347592 rad/s² |
| 双臂位置 RMS | 0.2144 mm |

基准使用固定初始姿态附近的已知可达双臂关节正弦路径，单关节幅度 0.02 rad、频率 0.1 Hz，全部 14 个臂关节参与。每个 5 ms 周期包含双臂 IK、MinSnap 重规划和 5 个 1 ms 仿真采样；简化执行模型每 1 ms 更新 `q_actual += 0.25 × (q_reference - q_actual)`。这是模型假设，不是对真实硬件带宽的测量。位置/姿态误差使用同一时刻原目标与实际模型状态比较，没有通过时间平移消除延迟。

配置中的 0.5 rad/s 是安全上限，并不表示已经在该速度下验证 1 mm 精度。200 Hz C++ 周期也不等于 PICO 有 200 Hz 新观测。普通桌面 Linux 的抖动表现见 [ENVIRONMENT.json](../validation/v1_0/ENVIRONMENT.json)；目标机器人设备必须重新运行基准。
